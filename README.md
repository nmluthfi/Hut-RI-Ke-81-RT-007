## 🚀 Cara Menjalankan Secara Lokal

Karena ini adalah website statis murni, cukup buka file `index.html` di browser Anda, atau gunakan *live server*:

```bash
# Menggunakan Python
python3 -m http.server 8080

# Menggunakan Node.js (npx)
npx serve .
```

Lalu buka `http://localhost:8080` di browser.
